# Rubber End AI
**Rubber End AI** — это специализированная нейросетевая модель для расчёта срока службы машинных шин.
## [Инструкция по установке](INSTALL.md)

## Начало работы
Вверху слева интерфейса главного меню можно переключить тему.

### Доступные режимы:
Выберите необходимый режим работы: **Default** или **Train**.

#### Режим Default (Прогноз)
Предназначен для запуска готовой модели.
* **Необходимые файлы:** `input.yaml`, `checkpoint.pth`.
* **Инструкция:** Введите данные и нажмите кнопку **Get a Prediction** для получения результата.

#### Режим Train (Обучение)
Предназначен для обучения новой модели.
* **Необходимые файлы:** `dataset.csv`, `checkpoint.pth` (во второй будет сохранена модель).
* **Настраиваемые параметры:** 
  * `Epochs` (количество эпох)
  * `Patience` (терпение для ранней остановки)
  * `Learning rate` (скорость обучения)
* **Управление:** Используйте кнопки **Start** и **Stop** для контроля процесса.
> Кнопка **Main Menu** возвращает на главную страницу приложения из любого режима.
